- **Apache Flink 2.2.0**：作为流计算引擎，支持 Delta Join 算子。

### 设计数据流程：基于 PostgreSQL + Flink + Fluss 的国网业务数仓分层
以下流程将文章中的 Delta Join 概念适配到国网业务场景，使用 PostgreSQL 作为源数据库，Python 脚本生成测试数据，并通过 Flink 和 Fluss 构建分层数仓（ODS → DWD → DWS → ADS），最终结果导入 Doris 并设置看板。

#### 1. **环境准备**
- **源数据库**：PostgreSQL，存储国网业务数据（如电表读数、设备信息、用户数据）。
- **数据生成**：Python 脚本模拟增删改查操作，生成测试数据并写入 PostgreSQL。
- **计算引擎**：Apache Flink 2.2+，支持 Delta Join 和 CDC 连接器。
- **流存储**：Apache Fluss 0.8+，用于分层数仓的表存储。
- **结果存储**：Apache Doris，用于高效查询和看板展示。
- **看板工具**：可选 Grafana 或 Superset，连接 Doris 可视化数据。

#### 2. **数仓分层设计与 SQL 脚本**
以下 SQL 脚本基于 Flink SQL 语法，假设已配置 Fluss Catalog（`bootstrap.servers=localhost:9123`）。所有表需一次执行（保存为 `.sql` 文件，通过 `sql-client.sh` 运行）。

##### **步骤 1：创建 ODS 层（源数据接入）**
- PostgreSQL 表通过 Flink CDC 连接器捕获变更，写入 Fluss ODS 表。
- Python 脚本生成测试数据（如电表读数 `meter_reading`、设备表 `device_info`）。

```sql
-- 创建 Fluss Catalog
CREATE CATALOG fluss_catalog WITH (
  'type' = 'fluss',
  'bootstrap.servers' = 'localhost:9123'
);
USE CATALOG fluss_catalog;
CREATE DATABASE IF NOT EXISTS power_grid;
USE power_grid;

-- ODS 层：原始数据表（从 PostgreSQL CDC 导入）
-- 电表读数表（主键：meter_id, reading_time）
CREATE TABLE ods_meter_reading (
  meter_id BIGINT,
  reading_time TIMESTAMP(3),
  voltage DOUBLE,
  current DOUBLE,
  power_consumption DOUBLE,
  PRIMARY KEY (meter_id, reading_time) NOT ENFORCED
) WITH (
  'bucket.key' = 'meter_id',  -- Fluss 索引优化
  'table.delete.behavior' = 'IGNORE'  -- 忽略删除（简化处理）
);

-- 设备信息表（主键：device_id）
CREATE TABLE ods_device_info (
  device_id BIGINT,
  device_type VARCHAR,
  location VARCHAR,
  status VARCHAR,
  last_maintenance_time TIMESTAMP(3),
  PRIMARY KEY (device_id) NOT ENFORCED
) WITH (
  'table.delete.behavior' = 'IGNORE'
);
```

##### **步骤 2：创建 DWD 层（数据清洗与关联）**
- 使用 Delta Join 关联 ODS 表，确保低状态消耗。
- 示例：关联电表读数和设备信息，过滤无效数据。

```sql
-- DWD 层：清洗和关联数据
CREATE TABLE dwd_meter_reading_enriched (
  meter_id BIGINT,
  reading_time TIMESTAMP(3),
  voltage DOUBLE,
  current DOUBLE,
  power_consumption DOUBLE,
  device_type VARCHAR,
  location VARCHAR,
  PRIMARY KEY (meter_id, reading_time) NOT ENFORCED
);

-- 插入数据：Delta Join 关联 ODS 表
INSERT INTO dwd_meter_reading_enriched
SELECT 
  r.meter_id, 
  r.reading_time, 
  r.voltage, 
  r.current, 
  r.power_consumption,
  d.device_type,
  d.location
FROM ods_meter_reading AS r
INNER JOIN ods_device_info AS d ON r.meter_id = d.device_id
WHERE r.voltage > 0;  -- 清洗条件
```

##### **步骤 3：创建 DWS 层（轻度聚合）**
- 按时间窗口聚合电表读数，生成每小时用电量统计。

```sql
-- DWS 层：小时级聚合
CREATE TABLE dws_hourly_power_summary (
  window_start TIMESTAMP(3),
  window_end TIMESTAMP(3),
  location VARCHAR,
  total_power_consumption DOUBLE,
  avg_voltage DOUBLE,
  PRIMARY KEY (window_start, location) NOT ENFORCED
);

-- 插入数据：滚动窗口聚合
INSERT INTO dws_hourly_power_summary
SELECT
  TUMBLE_START(reading_time, INTERVAL '1' HOUR) AS window_start,
  TUMBLE_END(reading_time, INTERVAL '1' HOUR) AS window_end,
  location,
  SUM(power_consumption) AS total_power_consumption,
  AVG(voltage) AS avg_voltage
FROM dwd_meter_reading_enriched
GROUP BY TUMBLE(reading_time, INTERVAL '1' HOUR), location;
```

##### **步骤 4：创建 ADS 层（应用层）**
- 生成告警或业务指标，如异常用电检测。

```sql
-- ADS 层：异常用电告警
CREATE TABLE ads_power_anomaly (
  meter_id BIGINT,
  reading_time TIMESTAMP(3),
  power_consumption DOUBLE,
  expected_consumption DOUBLE,
  anomaly_score DOUBLE,
  PRIMARY KEY (meter_id, reading_time) NOT ENFORCED
);

-- 插入数据：基于规则检测异常
INSERT INTO ads_power_anomaly
SELECT 
  meter_id,
  reading_time,
  power_consumption,
  AVG(power_consumption) OVER (PARTITION BY meter_id ORDER BY reading_time ROWS BETWEEN 10 PRECEDING AND CURRENT ROW) AS expected_consumption,
  ABS(power_consumption - expected_consumption) / NULLIF(expected_consumption, 0) AS anomaly_score
FROM dwd_meter_reading_enriched
WHERE ABS(power_consumption - expected_consumption) > 0.5 * expected_consumption;  -- 阈值规则
```
